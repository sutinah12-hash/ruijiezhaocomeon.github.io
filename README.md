# ruijiezhaocomeon.github.io
A robotics enthusiast exploring the intersection of mechatronics, AI, and autonomous navigation, dedicated to building intelligent systems that interact with the real world.Academic homepage of Ruijie Zhao, Tongji University.

## 更新主页 / Update the website

中英文内容集中在 `site-source/content.mjs`，共用样式在 `assets/site.css`。修改后在仓库根目录运行 `node site-source/build.mjs`，并提交更新生成的 HTML。GitHub Pages 直接读取生成的文件。

The Chinese and English content lives in `site-source/content.mjs`. Run `node site-source/build.mjs` from the repo root after editing and commit the generated HTML. GitHub Pages serves the generated files directly.
