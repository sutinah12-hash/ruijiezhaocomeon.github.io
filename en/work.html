Research

Jun 2026–present · Independent development

Embodied Spatial Perception and Memory

I’m building spatial semantic memory on a Unitree Go2 quadruped, combining LiDAR SLAM, text, visual features, and robot poses to support voice tagging and natural-language retrieval.

The system organizes spatial memories as SemanticTag triples. I explored guide and user preference memory and compared Fast DDS and Cyclone DDS to investigate ROS 2 memory issues.

ROS 2 / LiDAR SLAM / Unitree Go2

Jan–May 2026 · Reproduction and deployment

Vision-and-Language Navigation (VLN)

I set up the VLN-CE evaluation environment, reproduced ETPNav and CityNav, and deployed LightNav on the Go2.

The work took language-guided autonomous navigation from simulation evaluation to deployment on a physical robot.
